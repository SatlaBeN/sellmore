# גלגל מזל ללייב בטיקטוק

מערכת קטנה שרצה על המחשב שממנו משדרים. היא מתחברת ללייב, סופרת את המתנות שהצופים שולחים, ובכל פעם שצופה מגיע לסכום שהוגדר (למשל 1000 מטבעות) מופיע על המסך גלגל שמסתובב בשבילו ומראה את התוצאה.

```
TikTok LIVE ──מתנות──▶ server.js ──WebSocket──▶ overlay.html  (הגלגל, מתווסף לשידור)
                          │                 └──▶ control.html  (לוח בקרה ובדיקות)
                          └──▶ results.csv  (מי סובב ומה יצא)
```

## מה צריך

- [Node.js](https://nodejs.org) בגרסה 20 ומעלה.
- לשדר דרך **TikTok LIVE Studio** או **OBS** במחשב. אי אפשר להוסיף שכבה כזו כשמשדרים רק מהאפליקציה בטלפון.

## התקנה והפעלה

```bash
cd tiktok-wheel
npm install
```

פותחים את `config.json` וכותבים בשדה `tiktokUsername` את שם המשתמש בטיקטוק (בלי @). אחר כך:

```bash
npm start
```

- לוח הבקרה: http://127.0.0.1:8080/control.html
- הגלגל (להוספה לשידור): http://127.0.0.1:8080/overlay.html

אפשר לבדוק הכול עוד לפני שעולים ללייב: בלוח הבקרה לוחצים על "שליחת מתנת בדיקה" ורואים את הגלגל מסתובב בתצוגה המקדימה.

## הוספת הגלגל לשידור

**TikTok LIVE Studio:** הוספת מקור ← Link (קישור) ← מדביקים את כתובת ה-overlay. גודל מומלץ: 720×820.

**OBS:** Sources ← + ← Browser ← מדביקים את הכתובת, Width ‏720, Height ‏820. כדי לשמוע את צליל הגלגל בשידור מסמנים "Control audio via OBS".

הרקע שקוף, כך שהגלגל מופיע מעל הווידאו רק כשיש סיבוב ונעלם אחריו.

## הגדרות (`config.json`)

| שדה | מה הוא עושה |
|---|---|
| `tiktokUsername` | שם המשתמש שמשדר |
| `coinsPerSpin` | כמה מטבעות שווה סיבוב אחד (ברירת מחדל 1000) |
| `accumulateGifts` | `true`: מתנות קטנות של אותו צופה מצטברות עד שמגיעים לסכום. `false`: רק מתנה בודדת (או קומבו) שמגיעה לסכום בבת אחת |
| `maxSpinsPerGift` | הכי הרבה סיבובים ממתנה אחת (למשל אריה ב-29,999 מטבעות ייתן 3 ולא 29). ‏0 = בלי הגבלה |
| `spinDurationMs` | כמה זמן הגלגל מסתובב (במילישניות) |
| `resultDisplayMs` | כמה זמן התוצאה נשארת על המסך |
| `alwaysVisible` | `true` אם רוצים שהגלגל יוצג כל הזמן ולא רק בזמן סיבוב |
| `title` | הכותרת שמעל הגלגל |
| `segments` | המשבצות בגלגל: `label` הוא הטקסט, `weight` הוא הסיכוי, `color` הוא הצבע |
| `signApiKey` | לא חובה. ראו "פתרון בעיות" |

**הגלגל הוגן:** גודל כל משבצת על המסך הוא בדיוק לפי ה-`weight` שלה, כך שהצופים רואים את הסיכוי האמיתי. משבצת עם `weight` כפול תופיע גדולה פי שניים. התוצאה נבחרת בשרת, והגלגל נעצר עליה.

אחרי שמשנים את `config.json` צריך לעצור את השרת (Ctrl+C) ולהפעיל שוב `npm start`.

## איך נספרות המתנות

- מתנה בקומבו (למשל 50 ורדים ברצף) נספרת פעם אחת, כשהקומבו נגמר, לפי הכמות הסופית.
- כמה צופים ששולחים בבת אחת נכנסים לתור, והגלגל מסתובב לכל אחד בתורו.
- כל סיבוב אמיתי נשמר ב-`results.csv` (אפשר לפתוח באקסל) עם השעה, הצופה, המתנה והתוצאה. סיבובי בדיקה לא נשמרים.
- הצבירה של מתנות קטנות נשמרת בזיכרון, כך שהפעלה מחדש של השרת מאפסת אותה.

## חשוב לפני שמשתמשים: המדיניות של טיקטוק

לפי המדיניות של טיקטוק, הימורים הם מצב שבו משלמים כסף או "כל דבר בעל ערך" כדי לקבל סיכוי לזכות בפרס, ו"lucky spins" ומנגנוני גלגל מוזכרים שם במפורש. מתנות בלייב הן כסף. לכן גלגל שבו צופה שולח מתנה ויכול לזכות בפרס כספי או במוצר, או לצאת בלי כלום, עלול להיחשב הימור. התוצאה יכולה להיות הורדת הלייב, הגבלת המונטיזציה או חסימת החשבון. גם בחוק בישראל יש הגבלות על משחקי מזל והגרלות בתשלום.

לכן בקובץ ההגדרות כאן יש כברירת מחדל **גלגל אתגרים**: הגלגל קובע מה **המשדר** עושה (שיר, ריקוד, שאוטאאוט), כל משבצת היא משהו, ואין "הפסד". אם בכל זאת רוצים פרסים בעלי ערך כספי, כדאי לבדוק קודם את התנאים של טיקטוק ולהתייעץ עם עורך דין.

## פתרון בעיות

- **"לא מחובר (הלייב כבוי?)":** החיבור מצליח רק כשהלייב באוויר. השרת מנסה להתחבר מחדש כל 30 שניות, כך שאפשר להפעיל אותו לפני שעולים ללייב.
- **שגיאות חתימה או "rate limit":** הספרייה שמתחברת לטיקטוק ([tiktok-live-connector](https://github.com/zerodytrash/TikTok-Live-Connector)) משתמשת בשירות חיצוני בשם Euler Stream. אם מקבלים שגיאות כאלה, אפשר לפתוח מפתח ב-[eulerstream.com](https://www.eulerstream.com) ולשים אותו ב-`signApiKey`.
- **הספרייה לא רשמית.** היא עובדת דרך ה-API הפנימי של טיקטוק, וכשטיקטוק משנה משהו לפעמים צריך לעדכן אותה (`npm install tiktok-live-connector@latest`).
- **השרת זמין רק מהמחשב הזה** (`host: 127.0.0.1`). כך אף אחד ברשת לא יכול לשלוח סיבובי בדיקה.
